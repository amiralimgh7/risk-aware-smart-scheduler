# یادداشت تحویل نهایی کد

این بسته نسخه نهایی کد پروژه کارشناسی سید امیرعلی مقدسی است و برای ارسال به استاد راهنما آماده شده است.

## محتویات بسته

- کد کامل تولید داده، آموزش، شبیه‌سازی و گزارش‌سازی؛
- روش‌های پایه HEFT، EDF-VD، NSGA-III و GCN کلاسیک؛
- روش پیشنهادی مبتنی بر GAT، CVaR، قابلیت اطمینان، فرسودگی و DVFS؛
- ارزیابی چندی‌سازی شامل FP32، QAT INT8، وزن‌محور INT8 و FP16؛
- تست‌های پایه و توسعه‌یافته؛
- مستندات اجرای کامل و اجرای فقط گزارش.

## بررسی‌های انجام‌شده

- همه فایل‌های پایتون parse و compile شدند.
- تست‌های `test_phase_1.py` و `test_phase_2_and_3.py` اجرا شدند.
- همه توابع و کلاس‌ها دارای docstring هستند.
- همه نام فایل‌های پایتون و توابع عمومی snake_case هستند.
- فایل‌های cache و خروجی‌های موقت حذف شده‌اند.
- Dynamic INT8 Linear در گزارش نهایی استفاده نمی‌شود.

## دستور تست سریع

```powershell
python -m compileall -q .
python -m pytest -q tests/test_phase_1.py tests/test_phase_2_and_3.py
```

نتیجه مورد انتظار:

```text
9 passed
```
